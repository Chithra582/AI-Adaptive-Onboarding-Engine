# Adaptive Roadmap Generation Skill

## Overview
Synthesizes a structured milestone curriculum targeting identified candidate skill gaps, assigning estimated completion durations, stages (Upskill, Foundation, Application), and reputable resource links.

## Implementation
- **Curriculum Sequencing**: Knowledge-tracing based progression
- **LLM Synthesis**: Dynamic advice generation via Mistral-7B

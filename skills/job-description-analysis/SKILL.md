# Job Description Analysis Skill

## Overview
Parses unstructured job description text, normalizes skill variants to standardized O*NET terminology, and isolates required vs preferred competencies.

## Implementation
- **Text Normalization**: Lowercase tokenization and punctuation stripping
- **Taxonomy Mapping**: Standardized 150+ technology taxonomy dictionary
